## Design Context

### Users
Hackathon judges and a small-company release owner inspect a synthetic service graph, verify dependencies, ownership, source evidence, and decision history, then review any proposed memory update.

### Brand Personality
Precise, calm, accountable. The interface should make evidence and uncertainty easy to assess.

### Aesthetic Direction
Light editorial operations console. Geist Sans for interface text and Geist Mono for labels and identifiers. Ink text, pale neutral surfaces, hairline borders, and restrained `#006bff` accents. No orange, emoji, gradients, glass effects, or decorative hero art.

### Design Principles
- Put evidence before conclusions; keep paths, source excerpts, and immutable identifiers inspectable.
- Distinguish current rationale from historical decisions and incomplete or conflicting evidence.
- Make review a deliberate human step; show the exact text and citations before confirmation.
- Treat missing data, graph outages, stale reviews, and drafting failures as visible states.
- Use semantic controls, keyboard access, readable contrast, and reduced-motion support.
